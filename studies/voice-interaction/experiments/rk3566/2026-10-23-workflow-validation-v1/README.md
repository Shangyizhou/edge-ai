# 香橙派工作流验证：Qwen 与 ASR

日期：2026-10-23。对应 [#16](https://github.com/Shangyizhou/edge-ai/issues/16)。[两任务测评](comparison/report.html) · [总报告](../../mac/2026-10-23-workflow-pilot-v1/workflow-overview/report.html)。

## Qwen

已有基座Q4与新32微步技术Q4分别先独立冒烟，再各12条同一开发子集。均为llama.cpp / ARM CPU、2048上下文、q8 KV、前缀缓存；每阶段600秒内完成，仅清理本轮拥有的服务。冷首次独立冒烟约168.71 / 169.03秒；不能仅拿后续缓存请求代表交互等待。

原始Q4工具原生/Schema 6/9、精确5/9；技术Q4为8/9、6/9。角色自动规则均0/2，聊天1/1。24正式请求与2次冒烟都有原始事件/采样，不代表完整质量验收。运行环境和原始source保存在各run，未改生产项目或执行机器人动作。

## ASR 与保留失败

首次尝试执行了INT8的3次正式推理，随后旧报告器读取不存在的seconds字段失败，未执行FP32；`asr-experiment/`保留全部失败现场。薄适配层改为直接使用实际worker/sampler并读取compute_seconds / compute_rtf，`asr-experiment-v2/`在新目录完成两精度各3请求，共6次正式执行。首次失败的额外3次不被当成成功矩阵或隐藏。

混合INT8 / FP32 的3个inference窗口，计算RTF中位数约0.292 / 0.374，时长加权CPU约26.05% / 29.21%整机四核容量，采样峰PSS约112.86 / 156.00MiB。`asr-inference-summary.json`只读重算，排除加载、首请求、预热和待机。各自公开参考子集为30/66字符错误，CER45.45%；机器人命令的用户确认另列，不倒填独立参考。只有3份已知录音，4个有参考请求实际对应2份独立公开材料，不声称新的独立识别率验收。

原始inventory含硬件序列号的manifest在本机保留原字节并被本目录.gitignore排除公开提交，源hash仍保留；后续维护适配器已过滤该字段。其余原始事件、输出和失败不改写。实际运行源在execution-source；最终接口经Python3.8实际准备模式与无执行校验，区别于先前运行源的展示/兼容修订。

## 结论

同一通用实验交接已经承载两类任务，评分/计时各自独立。新Qwen不晋升主候选，ASR小子集不能推断整体质量；未执行ROS共跑、TTS、真实动作或生产替换。源文件和模型均保持原位置，不覆盖旧实验。
