# 模型研究方法

先读[轻量评测SOP](model-evaluation-sop.md)，理解从设备与候选到单模块、复测、共跑和应用的顺序；再按[结果数据契约](result-format.md)生成JSON与静态HTML。

此前讨论记录见[仓库外归档](../../archives/README.md)，不作为当前实验结果入口。每个研究主题的目标、进度、推荐和证据放在`studies/<topic>/`，避免把具体模型的结论堆入通用方法。

当前实例：[语音交互主题](../../studies/voice-interaction/README.md) · [本轮ASR三条有声材料](../../studies/voice-interaction/experiments/rk3566/2026-10-22-asr-three-samples-v1/README.md)。

## 怎样组织主题文档

SOP检查项保持完整，日常阅读入口合并为四页：首页写当前建议、关键数据和下一步；准备页合并目标、环境、候选和测试规则；单模型对比页合并筛选、复测及优化复验；应用验证页分别说明共跑、生产接入和完整体验。实例见[语音交互首页](../../studies/voice-interaction/README.md)。

不按“阶段×模型”预建页面，先用模块小节，真正过长时再拆。设备与通用指标链接复用，实际执行配置仍随实验冻结。新运行产生新数据和证据；正文解释选择理由，不逐轮复制日志。一份证据可被多处引用，不复制成不同版本。

首页概括最新判断，具体依据在对应详情页维护；历史实验保留当时事实，不随当前建议重写。三环节是展示与管理方式，不改变SOP七步的比较、质量及推进条件。
