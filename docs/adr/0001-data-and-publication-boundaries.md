# 数据身份、原始实验与公开报告分开维护

状态：接受，2026-10-23；对应 #17。

多轮模型实验与 HTML 原型混在实验目录时，按目录递归发布容易把原始样本和设备明细带到 Pages，也难以说明一次结论使用哪版数据。

采用版本化数据清单及派生实验索引。内容 SHA256 用于身份检查；路径仅作为定位。历史未知关联保留未知。原始证据不因总结更新而覆盖。录音、权重和完整数据备份放 Git 外，恢复验证写成清单。

报告由仓库内生成器从冻结证据生成，发布使用逐文件 SHA256 白名单。目录中未登记的 HTML 和 JSON 不会自动进入站点。报告布局可持续改进，但不能修改历史测量或将流程试跑称为模型验收。

代价：更换公开报告必须显式更新清单；旧的所有实验 URL 不再默认可访问。现阶段无需引入 DVC、实验数据库或新 Skill。若数据规模、协作权限或恢复时间目标增长，再评估专用工具。
